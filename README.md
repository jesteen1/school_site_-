## 📌 Project Purpose & Engineering Focus

Many traditional institutional portals rely on outdated layouts or heavy third-party templates. This project is a **pure frontend engineering showcase** designed to demonstrate how to build a responsive, interactive, and visually dynamic web portal using **100% custom CSS**.

### Key Highlights:
- **Zero Frameworks or Libraries:** Built without Tailwind, Bootstrap, React, or build tool dependencies.
- **Hand-Crafted Custom CSS:** Designed using native CSS Flexbox, Grid systems, CSS Variables (`--root`), and custom `@keyframes` keyframe animations.
- **Lightweight Runtime Performance:** Zero npm bundle size, allowing the website to load instantly with minimal browser rendering overhead.
- **Pixel-Accurate Layout Replication:** Recreated core institutional layouts including the header navbar, hero section, announcement ticker, event grid, and footer.

---

## ✨ Features & Custom CSS Animations

- 🎨 **Pure CSS Motion Effects:**
  - Keyframe-driven floating headers, hero banner fades, and scroll reveal animations.
  - Hardware-accelerated hover transforms (`transform: translateY()`, `scale()`) on cards and navigation buttons.
  - Custom CSS continuous scroll ticker for live school notices and news.
- 📱 **Responsive Design via Custom `@media` Queries:** Layout engineered to adapt across desktop monitors, tablets, and mobile screens.
- 🍔 **Vanilla JS Controls:** Lightweight DOM scripts to handle mobile navigation toggles and smooth scrolling.

---

## 🛠 Tech Stack

- **Markup:** HTML5 (Semantic elements)
- **Styling & Animation:** Pure Custom CSS3 (`@keyframes`, CSS Variables, Flexbox, Grid)
- **Scripting:** Vanilla JavaScript (ES6 DOM API)
- **Hosting / Deployment:** GitHub Pages / Vercel
